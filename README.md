# QA Automation - Page Object Model (POM)

Projeto desenvolvido durante o Bootcamp de QA da TripleTen.

## Objetivo

Aplicar automação de testes Web utilizando o padrão Page Object Model (POM), tornando o código mais organizado, reutilizável e de fácil manutenção.

## Atividades Realizadas

- Implementação de testes automatizados
- Estruturação do projeto com POM
- Criação de classes de páginas
- Organização de elementos e métodos
- Execução de testes automatizados

## Tecnologias Utilizadas

- Python
- Selenium WebDriver
- Pytest
- Page Object Model (POM)
- Git
- GitHub

## Competências Desenvolvidas

- Automação de testes
- Organização de código
- Boas práticas de QA
- Manutenção de testes
- Controle de versão com Git
